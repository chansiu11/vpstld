# Fencing Duel

오리지널 픽셀 아트로 구현한 브라우저용 1대1 검술 대전 프로토타입입니다.
2014년작 Nidhogg의 진행 방식에 영감을 받은 **비공식 팬 프로젝트**입니다. 게임의 원본 이미지, 오디오, 코드, 로고를 포함하지 않습니다.

## 실행
- GitHub Pages에 이 저장소의 **main / root**를 배포합니다.
- 웹사이트: https://chansiu11.github.io/vpstld/
- 별도 빌드 과정 없음. index.html 파일을 열어도 로컬/AI 대전 가능.

## 조작
- 1P: A/D 이동, W/S 검 높이, F 공격, G 점프, H 던지기.
- 2P: 방향키 이동/검 높이, K 공격, L 점프, ; 던지기.
- 검을 잃으면 떨어진 검 주변에서 아래 방향을 누르면 줍습니다.
- 이동 중 아래 방향 + 점프로 구르기, ESC 메뉴.
- 모바일은 게임 아래 표시되는 터치 버튼 사용.

## 온라인 대전 (선택 사항)
온라인 모드는 전용 WebSocket 릴레이 서버가 필요합니다.
1. Render에서 **New → Web Service**로 이 GitHub 저장소 연결 (루트 디렉터리 유지).
2. Runtime Node, Build Command \`npm install\`, Start Command \`npm start\`.
3. 배포된 Render 주소를 \`wss://<서버주소>\` 형태로 웹 게임의 '온라인 대전' 화면에 입력합니다.
4. 두 이용자가 같은 ROOM CODE를 입력하여 입장합니다.

현재 네트워크 방식은 **호스트 권한형 프로토타입**입니다. 서버는 입력과 상태 메시지를 전달하며, 판정은 1P 브라우저에서 실행됩니다. 경쟁용 서버 권한 판정/지연 보정은 별도 개발이 필요합니다.

## 주의
- 현재는 엔진과 게임 플레이를 먼저 구현한 **초기 버전**입니다.
- 원작과 픽셀 단위의 시각적 일치, 모든 모션·충돌·스테이지 구조, 게임패드 조작은 아직 검증하거나 구현하지 못했습니다.
- 원작 자료를 그대로 공개 배포하지 않습니다.
